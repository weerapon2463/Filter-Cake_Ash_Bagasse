# ระบบยื่นคำขอสิ่งปฏิกูลที่ไม่ใช้แล้ว ออนไลน์

กากใบอ้อย · ขี้หม้อกรอง (กากตะกอนหม้อกรอง) · ขี้เถ้า (ขี้เถ้ากากอ้อย) — ปีการผลิต 2569/70
ใช้กับขั้นตอนของฝ่ายความปลอดภัยฯ และสิ่งแวดล้อม: ชาวไร่ → หัวหน้าเขต → แผนกสิ่งแวดล้อม (ตรวจผ่าน = **เสร็จ** — ขั้นกรมโรงงาน/ตั๋วนำออก แผนกสิ่งแวดล้อมทำนอกระบบ)

## หน้าเว็บ
| หน้า | ใช้โดย | ทำอะไรได้ |
|---|---|---|
| `index.html` | ชาวไร่ (ไม่ต้อง login) | ดูเอกสารที่ต้องเตรียม/ขั้นตอน/ปฏิทิน, ยื่นคำขอ + ถ่ายรูปเอกสารแนบ, ตรวจสถานะด้วยเลขที่คำขอ + เบอร์โทร, แนบเอกสารเพิ่ม |
| `staff.html` | หัวหน้าเขต / แผนกสิ่งแวดล้อม / ผู้ดูแลระบบ (PIN 6 หลัก) | ดูคำขอ (หัวหน้าเขตเห็นเฉพาะเขตตัวเอง), คีย์คำขอแทนชาวไร่, เช็คลิสต์ตรวจเอกสาร, เปลี่ยนสถานะทีละรายหรือเป็นกลุ่ม, พิมพ์ใบปะหน้าเขต, ส่งออก CSV · ผู้ดูแลระบบ: ตั้งสถานะใดก็ได้, ลบไฟล์, ลบคำขอถาวร |
| `admin.html` | ผู้ดูแลระบบ (บทบาท `admin`) | 📊 รายงาน (ตามสถานะ / เขต × ชนิด, เลือกปี, CSV) · 👥 ผู้ใช้ (เพิ่ม/แก้/พัก/ลบ, ออก PIN ใหม่ — PIN แสดงครั้งเดียว) · ⚙️ ตั้งค่า (เปิด-ปิดรับคำขอ, ประกาศหน้าแรก, ปีการผลิต, ตัน/ไร่, เขต, ปฏิทิน, เงื่อนไข, เบอร์ติดต่อ) · 📜 บันทึกการใช้งาน |

**บทบาท:** `zone` หัวหน้าเขต (เฉพาะเขตตัวเอง) ⊂ `env` แผนกสิ่งแวดล้อม (ทุกเขต ปิดคำขอได้) ⊂ `admin` ผู้ดูแลระบบ (ทุกอย่าง + หลังบ้าน)
**ผู้ดูแลระบบคนแรก (ระบบจริง):** backend เพิ่มแถว "ผู้ดูแลระบบ" พร้อม PIN สุ่มในแท็บ `ผู้ใช้` ของ Google Sheet ให้อัตโนมัติ — เปิด Sheet ดู PIN แล้วเข้า `admin.html` (เปลี่ยนชื่อ/ออก PIN ใหม่ได้ในหน้าผู้ใช้)

**สถานะ:** ยื่นคำขอ → เขตตรวจแล้ว ส่งสิ่งแวดล้อม → (ต้องแก้ไข) → **เสร็จ** (แผนกสิ่งแวดล้อมตรวจเอกสารผ่าน) · หรือ ยกเลิก

**เลขที่คำขอ:** ปี พ.ศ. + ลำดับ เริ่มใหม่ทุกปี เช่น `2569-0001` (Apps Script เก็บตัวนับใน Script Property `SEQ_<ปี>`) · ไม่มีช่อง "เล่มที่"
จำนวนที่ขอคำนวณอัตโนมัติ = ไร่ × 20 ตัน · กันยื่นซ้ำ (บัตรประชาชน + ชนิด + ที่ตั้งที่ดินเดียวกัน)

## โครงสร้างไฟล์
```
index.html, staff.html, admin.html
assets/config.js   ← ค่าเริ่มต้น: API_URL, ชื่อบริษัท, เบอร์ติดต่อ, ปีการผลิต, เขต, ปฏิทิน (ค่าที่แก้ในหลังบ้านเก็บในแท็บ "ตั้งค่า" และทับค่าในไฟล์นี้)
assets/logic.js    ← ตรรกะทั้งหมด (ใช้ร่วมกันระหว่างเว็บโหมดทดลอง และ Apps Script)
assets/app.js      ← API, ฟอร์มคำขอ, ตัวช่วย
assets/style.css
assets/logo.png    ← ตรา PS (จาก phitsanuloksugar.co.th) ใช้บนหัวเว็บ, favicon, ใบคำร้อง/PDF
apps-script/Code.gs ← backend Google Sheets + Drive
```

## ใบคำร้อง (เหมือนฉบับกระดาษ)
ฟอร์มออนไลน์เรียงช่องตาม "ใบคำร้องขอกากตะกอนหม้อกรอง" ของบริษัท (ข้าพเจ้า / เบอร์โทร / เลขบัตร / เขตอ้อยที่ / บ้านเลขที่ / ชนิด+จำนวนตัน/ปี / ทะเบียนโรงงาน 3-11(3)-1/37 พล. / ที่ดินมีเนื้อที่ / ประเภทรถ+ทะเบียน / เอกสาร 1–4 / เงื่อนไข 1–6)
ปุ่ม **🖨 พิมพ์ใบคำร้อง** (หลังยื่น และในหน้าเจ้าหน้าที่) พิมพ์ A4 หน้าตาเหมือนฉบับกระดาษ พร้อมช่องลงชื่อ ผู้ขอ / ผู้รับเรื่อง / ผู้อนุมัติคำขอ — ข้อความทะเบียนโรงงาน/เงื่อนไขแก้ได้ใน `assets/config.js` — หัวใบคำร้องมีตรา PS (`assets/logo.png`) ทั้งฟอร์มออนไลน์ ฉบับพิมพ์ และ `00 ใบคำร้อง.pdf`

## Backend ที่ติดตั้งแล้ว
- Google Sheet "คำขอสิ่งปฏิกูล 2569-70" + Apps Script (bound) อยู่ในโฟลเดอร์ Drive ของโปรเจกต์ · ไฟล์แนบเก็บในโฟลเดอร์ย่อย "ไฟล์เอกสารคำขอ"
- Web app URL อยู่ใน `assets/config.js` (API_URL) · อัปเดตโค้ดด้วย clasp: คัดลอก `apps-script/Code.gs` → Code.js และ `assets/logic.js` → Logic.js แล้ว `clasp push -f` + `clasp deploy -i <deployment id>` (URL เดิม)
- ครั้งแรกต้องให้เจ้าของเปิด Apps Script แล้วกด Run `setup` เพื่ออนุญาตสิทธิ์ (PIN จริงอยู่ในแท็บ `ผู้ใช้` ของ Sheet — ห้ามนำขึ้น repo)

## โหมดทดลอง (เดโมสาธารณะ)
เปิดลิงก์ด้วย `?demo=1` → ใช้ **backend เดโมกลาง** (Sheet "DEMO คำขอสิ่งปฏิกูล (ข้อมูลตัวอย่าง)" + Apps Script แยก ที่มีไฟล์ `Demo.gs`: `var DEMO_MODE = true;`)
ทุกคนเห็นข้อมูลตัวอย่างชุดเดียวกัน · ล้างกลับเป็นข้อมูลตัวอย่าง 8 รายทุกคืน 03:00 (`resetDemo`) · ไฟล์แนบเก็บในโฟลเดอร์ `DEMO เอกสารคำขอ 2569-70` แยกจากของจริง
ถ้า `DEMO_API_URL` ว่าง เดโมจะเก็บข้อมูลในเบราว์เซอร์แทน

ถ้า `API_URL` ว่าง หรือเปิดลิงก์ด้วย `?demo=1` (เช่น `index.html?demo=1` ใช้ฝึกอบรม) เว็บจะเก็บข้อมูลในเบราว์เซอร์เครื่องนั้นเท่านั้น (ใช้สาธิต/ทดสอบ)
PIN ทดลอง: แผนกสิ่งแวดล้อม `000000` · หัวหน้าเขต 1 `111111` · หัวหน้าเขต 5 `555555`

## ติดตั้ง backend จริง (Google Sheets)
1. สร้าง Google Sheet ใหม่ → ส่วนขยาย › Apps Script
2. วางไฟล์ `apps-script/Code.gs` เป็น `Code.gs` และสร้างไฟล์ `Logic.gs` วางเนื้อหา `assets/logic.js` ทั้งไฟล์
3. ตั้ง Time zone ของโปรเจกต์เป็น Asia/Bangkok → รันฟังก์ชัน `setup()` (อนุญาตสิทธิ์ Sheets/Drive)
   - ได้แท็บ `คำขอ` (ข้อมูล) และ `ผู้ใช้` (PIN สุ่มให้แล้ว — แก้/เพิ่มหัวหน้าเขตได้ในแท็บนี้: PIN, ชื่อ, บทบาท `env`/`zone`, เขต)
   - ได้โฟลเดอร์ Drive "คำขอสิ่งปฏิกูล — ไฟล์เอกสาร" (แยกโฟลเดอร์ย่อยตามเลขที่คำขอ)
4. Deploy › New deployment › Web app — Execute as: **Me**, Who has access: **Anyone** → คัดลอก URL `…/exec`
5. ใส่ URL ใน `API_URL` ของ `assets/config.js` แล้ว push
6. ไฟล์เอกสาร (บัตรประชาชน/โฉนด) เป็นไฟล์ส่วนตัวของเจ้าของ Drive — **แชร์โฟลเดอร์ให้อีเมลเจ้าหน้าที่แผนกสิ่งแวดล้อมเท่านั้น** อย่าตั้งเป็น "ทุกคนที่มีลิงก์"

## ความปลอดภัย / ข้อมูลส่วนบุคคล
- ข้อมูลอยู่ใน Google Sheet ส่วนตัว — หน้าเว็บ (GitHub Pages) ไม่มีข้อมูลใด ๆ
- ตรวจสถานะสาธารณะต้องใช้เลขที่คำขอ + เบอร์โทร และไม่แสดงเลขบัตร/ที่อยู่/ชื่อเต็ม
- ค้นสถานะไม่พบ 10 ครั้งใน 10 นาที เครื่องนั้นต้องรอ 10 นาที (กันเดาเบอร์โทร/เลขคำขอ) · ผู้ขอแนบใบคำร้อง/ลายเซ็นได้ครั้งเดียว
- มีประกาศการเก็บและใช้ข้อมูลส่วนบุคคล (PDPA) ในใบคำร้อง
- PIN ผิด 5 ครั้งใน 10 นาที เครื่องนั้นต้องรอ 10 นาที (เครื่องอื่นใช้ได้ตามปกติ) · ผิดรวมทั้งระบบเกิน 100 ครั้งใน 10 นาที ปิดการเข้าระบบชั่วคราว · มี honeypot กันบอท และจำกัดการยื่นต่อนาที
- อย่า commit ไฟล์ PDF/รายชื่อชาวไร่ขึ้น repo (ตั้ง `.gitignore` ไว้แล้ว)
